Incident flow (what good looks like)

Matches the Switch multi-human / multi-agent room pattern.

You → Ops — “Checkout failing on UAT, look please.”

Ops → tools — runs health / order-status, summarizes.

Ops → Release — asks for a UAT rollback proposal.

Release — proposal only; waits for admin.

Teammate says Rejected — agent tags owner: Admin permission required.

Owner: Approved / Rejected — only this counts as the decision.

Why Switch is mandatory

With Switch

  • Telegram group becomes a shared room with Rules
  • Cursor agents join as named teammates
  • Handoffs + admin trust in one thread
  • History of who Approved stays in the room

Without Switch

  • No room bridge into Telegram
  • Agents stay stuck in a local IDE
  • No shared Rules / who-can-talk controls
  • This product design does not work
