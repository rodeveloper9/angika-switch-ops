# Setup checklist

## Switch
- [ ] Switch Console installed
- [ ] Local or team Switch server running
- [ ] Agent provider signed in (**Cursor** recommended)
- [ ] At least one agent onboarded

## Telegram
- [ ] Bot created with BotFather
- [ ] Telegram connected in Switch
- [ ] Group created; Switch room exists (`#angika-ops`)
- [ ] Humans + agents invited

## Angika tools
- [ ] `.env` from `.env.example`
- [ ] `ANGIKA_TOOLS_MODE=mock` works offline
- [ ] Optional: point `ANGIKA_API_BASE_URL` at UAT

## Room
- [ ] Rules pasted from `rooms/angika-ops/RULES.md`
- [ ] Demo script rehearsed once

## Judge share
- [ ] This repo public on GitHub
- [ ] README clone → demo path clear
- [ ] No secrets committed
